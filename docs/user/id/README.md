# Panduan Pengguna EasyFaceless Studio (Bahasa Indonesia)

Selamat datang di panduan resmi **EasyFaceless Studio**. Pilih topik di bawah ini untuk mempelajari alur produksi video faceless dari awal hingga ekspor ke CapCut Desktop.

## Daftar Panduan

1. **[Mulai Cepat](mulai-cepat.md)** — Alur lengkap dari membuat proyek hingga ekspor final (Naskah → Suara → Visual → Render → CapCut) serta mode Video Pendek.
2. **[Pengaturan API & Penyedia AI](pengaturan-ai.md)** — Konfigurasi penyedia LLM, TTS, Gambar AI, Video AI, perbedaan model gratis vs berbayar, serta arti kode error `402` / `404` / `429`.
3. **[Niche & Preset Kustom](niche-preset.md)** — Mengelola niche bawaan, sub-niche, preset kustom, dan **Jangkar Visual** agar pemilihan footage tetap akurat.
4. **[Galeri Visual & Shot](galeri-visual.md)** — Mengganti kandidat footage, mencari ulang manual, mengunggah klip, mengunci shot, memperbarui kata kunci AI, dan mengecek relevansi AI.
5. **[Ekspor ke CapCut Desktop](capcut-ekspor.md)** — Syarat versi teruji (**8.9.0**), alasan menutup CapCut sebelum ekspor, serta kalibrasi ukuran teks subtitle.
6. **[Tempat Sampah & Penghapusan Aman](tempat-sampah.md)** — Menghapus proyek dengan aman (termasuk saat proses berjalan), membersihkan draft CapCut opsional, dan memulihkan proyek.
7. **[FAQ & Pemecahan Masalah](faq-troubleshooting.md)** — Jawaban atas kendala umum seputar FFmpeg, progres, cache thumbnail, serta kunci API.
