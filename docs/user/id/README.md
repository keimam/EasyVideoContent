# Panduan Pengguna EasyFaceless Studio (Bahasa Indonesia)

Selamat datang di panduan resmi **EasyFaceless Studio**. Pilih topik di bawah ini untuk mempelajari alur produksi video faceless dari awal hingga ekspor ke CapCut Desktop.

## Daftar Panduan

1. **[Mulai Cepat](mulai-cepat.md)** — Alur lengkap video ±10 menit (Naskah → Suara → Visual → Render → CapCut), mode Video Pendek, perkiraan waktu benchmark CA1, dan kebutuhan sistem.
2. **[Pengaturan API & Penyedia AI](pengaturan-ai.md)** — Konfigurasi LLM, TTS, Gambar AI, Video AI, **Penyedia AI cadangan** (*Pengaturan → Umum*) beserta badge status & uji rantai AI, model Flash Gemini, dan error `402` / `404` / `429`.
3. **[Sumber Footage, Lisensi & Atribusi](sumber-footage.md)** — Daftar lengkap sumber stok & arsip (Pixabay, Coverr, Pexels, Wikimedia, Openverse, NASA, Internet Archive, Smithsonian BYOK, Local files, Gambar Eksternal), kuota, mode **Campur terbaik** vs **Prioritas**, dan `credits.md`.
4. **[Niche & Preset Kustom](niche-preset.md)** — Mengelola niche bawaan, sub-niche, preset kustom, dan **Jangkar Visual** agar pemilihan footage tetap akurat.
5. **[Galeri Visual & Shot](galeri-visual.md)** — Mengganti kandidat, **Local files**, status **Selesai sebagian**, serta panduan 3 tab **🖼️ Gambar Eksternal** (*Konteks Visual*, *Ekspor Prompt*, *Impor Gambar* untuk Google Flow & Zapi).
6. **[Ekspor ke CapCut Desktop](capcut-ekspor.md)** — Syarat versi teruji (**8.9.0** / **9.7.1**), alasan menutup CapCut sebelum ekspor, serta kalibrasi ukuran teks subtitle.
7. **[Tempat Sampah & Penghapusan Aman](tempat-sampah.md)** — Menghapus proyek dengan aman (termasuk saat proses berjalan), membersihkan draft CapCut opsional, dan memulihkan proyek.
8. **[FAQ & Pemecahan Masalah](faq-troubleshooting.md)** — Jawaban atas kendala **Local files**, kuota AI harian reset 07:00 WIB, Gemini `limit: 0`, Coverr 403 / Openverse timeout / profil **Lambat**, `Visual selesai: X dari Y shot`, Google Drive, dan SmartScreen.
