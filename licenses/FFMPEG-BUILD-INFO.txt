Invocation Architecture:
  EasyFaceless Studio bundles unmodified ffmpeg.exe and ffprobe.exe binaries under
  runtime/ffmpeg/bin/ and executes them strictly as separate external command-line
  subprocesses (never statically or dynamically linked into Python code).

LGPL Evaluation Note (D7):
  Both upstream MoneyPrinterTurbo (app/services/video.py) and the Long Video modules
  (visual/builder.py, render/chapter_render.py, audio_preview.py) currently invoke
  software H.264 encoding via `-c:v libx264`. Because x264 is GPL-licensed, LGPL-only
  Windows builds (such as BtbN FFmpeg-Builds win64-lgpl) exclude libx264/libx265 and
  instead provide libopenh264 / hardware MediaFoundation (`h264_mf`), NVENC (`h264_nvenc`),
  QSV (`h264_qsv`), or AMF (`h264_amf`). Switching to an LGPL build remains a documented
  future option if encoder defaults/fallbacks are updated accordingly.
