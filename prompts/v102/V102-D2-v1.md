## D2.1 — `InternetArchiveVisualProvider` (keyless)
- Modul baru `app/services/longform/visual/archive_providers.py`. Pencarian via `advancedsearch.php` dengan allowlist koleksi + filter `licenseurl` berkutip (PDM, CC0, publicdomain, CC BY, CC BY-SA). Ambil detail berkas via `/metadata/{id}`.
- **Penolakan klien wajib** (D1 §6.3): `licenseurl` kosong atau NC/ND; `rights` memuat Fair Use / Copyright / All Rights Reserved / Permission; koleksi di luar allowlist. Tes dengan contoh nyata dari D1 (`western-tradition`: PDM + "Fair Use Notice" harus ditolak).
- User-Agent deskriptif wajib (D1 §6.2). Hormati 429 + `Retry-After`. Pakai cache JSON 24 jam, pemutus B1/B3, profil jaringan, dan prefetch CA1 yang sudah ada.
- **Video:** pilih berkas `.mp4` h.264 640×480–1920×1080, hindari ProRes/MPEG-2 multi-GB. Potong segmen `target_duration + 1.5 dtk` lewat FFmpeg input-seeking langsung dari URL (HTTP Range), **tanpa mengunduh berkas penuh**. Offset awal menghindari judul/kredit (mis. mulai ≥10% durasi dan ≤ durasi − 10% − segmen). Shot berbeda dari film yang sama mendapat segmen berbeda (masuk dedup kandidat). Bila potong gagal, kandidat dilewati (bukan unduh penuh).
- **Gambar:** JPEG ≥1280 px bila ada, hindari TIFF raksasa.
- Kandidat membawa `license`, `license_url`, `creator`, `identifier`, URL halaman item, dan offset segmen (video).
