V1 — Prioritas & pencampuran sumber footage
Temuan: pencarian berhenti di sumber pertama yang lolos (Pixabay di urutan pertama) → uji D9: 49/50 shot dari Pixabay; Wikimedia/NASA/Openverse/Local hampir tak terpakai.
- Mode pencarian per proyek (default "Campur terbaik"):
  a. "Prioritas": urutan sumber yang bisa diubah pengguna (naik/turun) di panel Sumber footage; berhenti di sumber pertama yang lolos (perilaku lama).
  b. "Campur terbaik": cari di SEMUA sumber yang dicentang per shot (paralel, menghormati rate limit & cache D9.4), pilih kandidat dengan skor relevansi tertinggi.
- Keragaman: opsi "Batasi satu sumber maks. X% shot" (default 60%) dan "hindari klip dari sumber yang sama lebih dari 3 shot berturut-turut" — diterapkan hanya bila ada kandidat lain yang lolos ambang relevansi (relevansi tetap prioritas).
- Local files: bila dicentang dan ada kandidat lokal yang lolos ambang, selalu didahulukan.
- Ringkasan di langkah Visual: jumlah shot per sumber (mis. Pixabay 22 · Wikimedia 9 · Local 5 · Openverse 3 · Belum ada 1).
- Laporkan perbandingan pada proyek uji yang sama: distribusi sumber & waktu fetch untuk Prioritas vs Campur terbaik.

V2 — Local files mudah dipakai
- Di langkah Visual/panel Sumber footage: jumlah file di pustaka lokal proyek, tombol "Buka folder Local files" (membuka <proyek>\assets\visual\library lewat platform_utils, membuat folder bila belum ada), dan unggah banyak file langsung ke pustaka (pakai LocalLibraryManager).
- Panduan singkat di UI: nama file deskriptif bahasa Inggris (contoh), format didukung.
- Jelaskan & dokumentasikan aturan pencocokan LocalVisualProvider (termasuk apakah file lokal dipakai untuk shot yang tidak cocok kata kunci); bila ada perilaku "isi acak" tanpa kecocokan, jadikan opsi eksplisit default MATI.
- docs/user galeri-visual (id & en): bagian "Local files" lengkap (lokasi, penamaan, cara kerja).

V3 — Jembatan gambar eksternal (Flow/Midjourney/dll.)
- "Ekspor prompt gambar" untuk shot terpilih / tanpa visual / semua: .txt (satu blok per shot, diawali id shot) dan .csv (id shot, durasi, narasi singkat, prompt EN, rasio 16:9, gaya visual proyek). Prompt dari visual_prompt/ai_keywords; bila kosong dibuat dari narasi.
- "Impor gambar massal": banyak file png/jpg/webp/mp4; pencocokan (1) id shot di nama file, (2) urutan ekspor terakhir; layar konfirmasi pemetaan yang bisa diubah sebelum diterapkan. Gambar → klip Ken Burns sesuai durasi; actual_source="external_image"; shot otomatis terkunci; manifest tervalidasi (D8.1).
- credits.md: "Gambar dibuat pengguna dengan alat eksternal".
- Tanpa otomasi situs pihak ketiga. docs/user (id & en): alur Flow → ekspor → buat gambar → impor.

V4 — Preset penyedia gambar (OpenAI Compatible)
