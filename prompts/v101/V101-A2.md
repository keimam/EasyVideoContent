A2.4 Bug tombol "Uji 1 gambar" di Pengaturan
Temuan pengguna (build 16b98ba, UI en): preset DeepInfra terpilih, kolom Base URL berisi https://api.deepinfra.com/v1/openai, model black-forest-labs/FLUX-1-schnell, key palsu diisi → klik "Test 1 image" → error "OpenAI-compatible image Base URL is empty." Pesan key salah tidak pernah muncul.
Penyebab dari review kode (image_presets.py, render_openai_image_preset_controls): tombol memanggil test_single_openai_image(base_url=app_settings.get(...), model=..., image_size=...) dari dict app_settings yang dibaca sebelum kolom input di bawahnya dirender; nilai "" diteruskan sebagai string kosong (bukan None) sehingga fallback ke config tidak terjadi; api_key tidak diteruskan sama sekali.
- Perbaiki: tombol uji memakai nilai yang sedang tampil di form (session_state widget Base URL, key, model, size), dengan fallback ke config yang tersimpan bila kosong; string kosong diperlakukan sebagai "tidak ada". Hal yang sama untuk tombol uji di panel Sumber footage (components.py).
- Hasil uji lama di session_state dihapus saat preset/URL/key/model berubah, agar pesan basi tidak tampil.
- Tes: (a) form berisi URL+model+key palsu tanpa disimpan → uji mengirim request dan mengembalikan kategori key salah (mock 401), key tidak muncul di pesan; (b) URL benar-benar kosong → pesan URL kosong; (c) ganti preset → hasil uji lama hilang.
- Uji di aplikasi terpasang dengan key palsu ke DeepInfra dan Together (request nyata, harus 401/403 → pesan ramah, key tidak tampil). Screenshot id & en.
